素材庫

以固定素材 ID 連接故事。替換檔案時，所有引用會一起更新。

批次載入時，會優先對應相同檔名的素材。可選取多個檔案，也可直接拖曳到本頁。JSON 可攜版會內嵌已載入素材；大型影片建議改用 ZIP。

專案設定

AI 工作流

  1. 輸出「AI 生成 MD」，交給你使用的 AI。
  2. 讓 AI 按格式輸出 JSON 與素材清單，另行生成素材。
  3. 匯入 JSON / MD，再批次匯入素材。
  4. 改文字、分支、條件、結局與音樂，試玩檢查。
  5. 輸出遊戲 HTML 或 GitHub 遊戲 ZIP。

草稿保存

小型專案會自動存於本瀏覽器。容量不足時會提示；請用 JSON / MD 另存。清除瀏覽器資料、無痕模式或更換網址可能遺失本機草稿。
